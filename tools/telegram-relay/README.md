# Заявки с сайта → Telegram (Google Apps Script)

Сайт статический (GitHub Pages), поэтому токен бота **нельзя** хранить в коде сайта — его увидит любой посетитель.
Заявки идут так: форма на сайте → этот скрипт (токен хранится только в нём) → группа «Заявки с сайта».

## Развёртывание (≈5 минут, один раз)

1. Откройте https://script.google.com под Google-аккаунтом сервиса → **Новый проект**. Назовите «DIESEL-CRAFT заявки».
2. Удалите содержимое `Код.gs` и вставьте `Code.gs` из этой папки.
3. ⚙️ **Настройки проекта** → **Свойства скрипта** → добавьте:
   - `TELEGRAM_BOT_TOKEN` — токен бота от @BotFather;
   - `TELEGRAM_CHAT_ID` — ID группы (например, `-100…`).
4. Вверху выберите функцию `testTelegram` → **▶ Выполнить** → разрешите доступ. В группе появится «✅ Тест…».
5. **Развертывание → Новое развертывание** → тип **Веб-приложение**:
   - «Запуск от имени» — **Я**;
   - «У кого есть доступ» — **Все**.
   Нажмите **Развернуть** и скопируйте URL вида `https://script.google.com/macros/s/…/exec`.
6. Вставьте URL в `assets/telegram-leads.js` → `const telegramRelayEndpoint = '…/exec';` и опубликуйте сайт.

Пока URL не вставлен, формы работают по-старому (резервная копия + WhatsApp), заявки не теряются.

## Что делает скрипт
- принимает заявку (телефон, имя, услуга, авто, проблема, страница, язык, UTM/gclid);
- проверяет телефон, отсекает ботов (скрытое поле), повторную отправку одного номера в течение 60 с и больше 20 заявок в минуту;
- отправляет сообщение в группу с экранированием HTML.

## Обновление кода
После изменения `Code.gs`: **Развертывание → Управление развертываниями → ✏️ → Версия: новая → Развернуть**. URL не меняется.

## Если токен скомпрометирован
@BotFather → `/revoke` → новый токен → обновите `TELEGRAM_BOT_TOKEN` в свойствах скрипта. Сайт менять не нужно.
